## GitHub Release / README 片段

### 一句话

> 一个轻量、干净、划词即查的 Windows 中英词典：离线优先，在线补充，带 FSRS 生词复习。

### 功能

- 全局划词：选中文字出现小标志，点开才查，不打扰阅读
- 多来源：ECDICT、WordNet、CC-CEDICT、有道、柯林斯、Merriam-Webster
- 中英互译 / 英英互译 / 整句翻译
- 生词本 + FSRS-6 间隔复习
- 悬浮球快捷搜索、待复习角标
- 查询历史可勾选删除
- 本地数据，支持备份 / 恢复
