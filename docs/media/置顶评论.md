【下载 & 使用说明】

开源地址：
https://github.com/yuluo-zero/lexi-dictionary

便携版下载：
https://github.com/yuluo-zero/lexi-dictionary/releases/latest

Windows 10/11 64 位，免安装 Python，也不需要管理员权限：

1. 下载 lexi-dictionary-portable-v1.0.0.zip（约 193 MB）
2. 如果 Windows 提示“已阻止此文件”或“来自网络”：右键 ZIP → 属性 → 勾选“解除锁定” → 再解压
3. 解压到固定目录，双击 start.cmd；不想看到命令行窗口就双击 start.vbs
4. 数据都在解压目录的 data/ 里，删除整个文件夹即卸载
5. 在线词典需要联网；韦氏 Key 需要自己申请并填入设置，仓库和便携包里都不含 Key

如果 start.cmd 仍被拦截，也可以直接运行：
runtime\pythonw.exe main.py
